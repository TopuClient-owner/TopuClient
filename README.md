## ⚡ Features
* **2x FPS Boost:** Pre-configured with top-tier optimization mods (Sodium, Lithium, FerriteCore) for ultra-smooth gameplay.
* **Open Source & Transparent:** No malware, no hidden code—don't just trust, verify our code!
* **Dual Auth Support:** Seamlessly supports both **Offline/Cracked** and **Microsoft Official** accounts.
* **Utility Features:** Built-in mod downloader via Modrinth API, customizable RAM allocation, and fast server switching.

## 🚀 Getting Started
1. Head over to the [Releases](https://github.com/bettertoppi/TopuClient/releases) tab.
2. Download the latest version of **TopuClient**.
3. Run the launcher, enter your username or sign in, and enjoy high-performance Minecraft!
